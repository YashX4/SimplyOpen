# Examples from GitHub

Thirty real command-line projects copied from public GitHub repositories, to try SimplyOpen on code it was not written for. Each is MIT licensed; its licence file and a `SIMPLYOPEN_SOURCE.md` (repository, commit, what was added) are in its folder. The code is unchanged.

**None of these has been run.** Every `simplyopen.json` here was written by reading the code, so treat it as a first guess that the Analyzer and a real test run should replace.

- **Should open**: a Python script started with `python`, taking its inputs as options. Most still need packages installed.
- **Needs extra setup**: started through an installed command rather than `python`, hard-coded file names, or programs that must already be on the computer.
- **Not supported yet**: asks questions while running, or reads its data from another command's output.
