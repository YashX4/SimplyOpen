# Fonts

The design uses GT Canon and GT Standard from Grilli Type. They are trial
files with their own licence, so they are kept out of the repository.

To see the site exactly as designed on your own machine, copy these four
files from the Grilli Type trial download (the OTvar folder) into this folder:

    GT-Canon-Trial-VF.woff2
    GT-Canon-Italic-Trial-VF.woff2
    GT-Standard-Trial-VF.woff2
    GT-Standard-Mono-Trial-VF.woff2

Without them the site falls back to Fraunces and Inter.
